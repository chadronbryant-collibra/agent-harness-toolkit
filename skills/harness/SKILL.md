Read START-HERE.md for onboarding. Read the relevant docs/ file for routing,
memory, extensions, hooks or maintenance; do not preload every file.

For work, preserve objective, scope, authority, sources, acceptance, budget and stop
condition. Continue independent authorized steps. Delegate only when authorized,
with exact ownership and no overlapping writers. Verify returned artifacts.

For improvement, select at most three useful observations from the named task.
For each record the invariant, expected/observed behavior, evidence pointers, cause
(unknown/inferred/verified), proposed fix, owner and next check. Reproduce failures
with a known-bad case, implement authorized scoped fixes, then verify. Compare a
later outcome before claiming savings or general improvement. Unknown cost and
token savings stay unknown. Ask before changing budgets, permissions, retention
or routing policy. Never auto-capture the conversation as memory.

For stalled work, classify missing prerequisite, unsupported capability, denied
authority, implementation defect or ambiguous effect. An unchanged denial ends
that route. Verify run ownership and uncertain effects before any replay. Stop
when acceptance passes or a named dependency needs the user; report exact state.
