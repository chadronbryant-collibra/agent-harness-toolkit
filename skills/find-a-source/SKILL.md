name: find-a-source
description: Use when a question needs an answer with a link to a source in the user's reference library.
---

Read the selected index or reference-library/SOURCES.md. Choose the few entries that match the question. Open the source through the supported route if you have access. Check the scope, date, and evidence for the specific question. Cite the source and qualify any stale or conflicting evidence. If you cannot inspect it, report the exact limitation and keep the claim open.
