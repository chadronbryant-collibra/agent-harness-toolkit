---
name: build-a-skill
description: Turn a task the user repeats into a small project skill they can install and test.
---

Ask for one repeated request and one example of a good result. Check the current client's skill discovery path. If a matching skill exists, inspect it before proposing a new file. Draft a SKILL.md with the chosen name, a description of when to use it, the inputs, the work steps, and observable checks. Keep instructions short. Put optional commands in reference files when needed. Preview the target path and preserve existing files. After adding it within scope, have the user try it in a fresh session. Explain what actually ran and how to edit or remove the skill.
