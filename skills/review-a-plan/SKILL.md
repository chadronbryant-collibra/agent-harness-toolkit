---
name: review-a-plan
description: Give advice on a proposed plan before the user makes a change.
---

Identify the decision and expected outcome. Read the proposal and the sources the user names. Explain the smallest change that would improve the result and what to verify before proceeding. Identify any assumption that would change your recommendation. If the user asks for an independent review and the client supports it, give that reviewer a narrow question and check the returned evidence. Stay within the approved cost and access scope.
