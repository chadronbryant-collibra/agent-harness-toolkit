# Working in this folder

Use the local notes as evidence and cite the note heading behind each action. Keep source notes intact unless the user asks to change them. Mark unknown owners and pending decisions explicitly.

If the user asks to resume or asks about current blockers, check PROGRESS.md if present. Open the current notes it points to and resolve differences before answering. Tell the user if the progress note is stale. Use the current source to support each reported blocker.

When asked to record progress, include what is complete, what remains, the next check, and links to the plan and source notes. Keep the record short enough to read in a fresh session.
