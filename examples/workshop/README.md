# Plan a workshop FAQ

Open this folder in a local assistant session. The [workshop notes](notes.md) are fictional.

## First session

> Turn notes.md into ACTION-PLAN.md. Link each action to its source note. Flag any missing owner or decision and leave notes.md intact. In PROGRESS.md, record what’s complete, what’s open, and what to check next. Link to the plan and notes.

Check that Morgan owns the FAQ draft and that the accessibility reviewer is unassigned. Open a citation to check it leads back to the notes.

## Fresh session

Start a new session in the same folder and ask:

> What’s still blocking the workshop FAQ, and what should I do next?

Look for the unassigned accessibility reviewer and the steps that depend on that review. The answer should cite the current notes. If you later change a decision in the source, repeat the question in another new session to see whether it catches the change.
