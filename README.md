## Start here

You bring your work and preferences. The toolkit gives Claude a starting point for helping you build your own setup.

### ① Download and unpack

Use the ZIP you were sent, or [download the toolkit](https://github.com/chadronbryant-collibra/agent-harness-toolkit/archive/refs/heads/main.zip). Extract it into a folder you plan to keep, such as **Documents → Agent Toolkit**.

Keep the whole folder together. You do not need to understand every file before you begin. The download above follows the current guides; older release ZIPs remain dated snapshots.

### ② Open it with Claude

**Already using Claude Code?** Open the extracted folder in Claude Code.

**Starting in Claude chat?** Attach the file **START-HERE.md** from that folder. Claude can explain the setup and help you move into a local Claude session that can open and configure your files.

You only need access to Claude to start the conversation. Claude will guide you through anything else your computer needs.

### ③ Paste this message

```text
Help me set up this toolkit for my work. Follow START-HERE.md.

Find out what I want to use Claude for and what is already set up
on my computer. Recommend a simple, cost-conscious starting point.

Walk me through the choices one step at a time. Explain anything
I need to install, preserve my existing settings, and show me
what will change before applying it.

Help me choose which features to enable, set a spending limit,
and finish by walking me through a useful first task.
```

### ④ Make it yours

Claude will help you decide:

| Your choice | What it shapes |
| :--- | :--- |
| **The work you do** | The tasks, examples, and workflows worth setting up first. |
| **How much help you want** | When Claude should advise, take action, or involve another agent. |
| **Your budget** | Which models to use and when a more expensive option is worth considering. |
| **What to remember** | The preferences, decisions, and references you want available later. |
| **Your tools** | Which repositories, skills, plugins, and connections to add when you need them. |

**Start small.** Get one useful workflow working, then add features as your needs grow.

## What can you build with it?

| 🧭 Better decisions | 🤝 Help that follows through | 🧠 Useful context |
| :--- | :--- | :--- |
| Ask for advice, compare approaches, and choose a model suited to the work and budget. | Give a task a clear finish line, use agents with clearly defined tasks when helpful, and pick work back up after an interruption. | Choose what to remember and keep a reference library Claude can consult when relevant. |

The kit also gives you a way to review completed work, identify useful lessons, and improve your setup over time.

Memory is optional. Before enabling it, ask Claude to explain where information will be stored and what is appropriate to keep there.

## Try your first task

The toolkit includes a fictional project you can use without connecting any work accounts. Ask Claude:

> Walk me through the example in **examples/notes.md**. Turn it into a short action plan, keep the original notes unchanged, and show me where each action came from.

Then try a task from your own work. Tell Claude the result you want, the sources to use, and what a finished result should include.
