# Generic starter lessons

- A file being present does not mean the client loaded it. Verify discovery and
  invocation separately in a fresh session.
- A test passing does not prove installation, authentication or live integration.
- Preserve work before retrying; an uncertain write needs reconciliation.
- Give an executor an outcome, sources, scope, acceptance and stopping condition.
- Retrieve relevant context from an index; repeated whole-history injection is costly.
- Compare total completion cost and rework before changing model mappings.
- Keep one canonical source and thin client/platform adapters.
- A reviewed lesson needs evidence and a verified improvement, not only a summary.

These are newly written reusable methods, not exported personal memory records.
