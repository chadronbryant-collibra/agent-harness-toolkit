# Habits worth keeping

**Use these as starting habits, then keep the ones that help your work.** They are general lessons, not someone else's saved conversations or personal history.

| Habit | What it looks like |
| :--- | :--- |
| **Check that a feature works** | Open a fresh session and try it. A copied file or installed label is not the whole setup. |
| **Check the result** | Ask what was actually reviewed or tested, and what remains uncertain. |
| **Inspect before retrying** | If a change might already have happened, look at the current state before repeating it. |
| **Give a task a finish line** | Name the result, sources, allowed changes and checks. Let Claude handle routine steps. |
| **Bring in relevant context** | Read the few notes that matter instead of replaying the whole history. |
| **Compare completed work** | Consider quality, retries and total cost before changing model choices. |
| **Keep one source to maintain** | Update the original instructions, then the copies or packages that use them. |
| **Turn lessons into a check** | Show that a fix addresses the problem, then see whether it helps a later task. |

To use a lesson, ask Claude to apply it to a selected task. Saving it as your own lasting memory is a separate choice.
