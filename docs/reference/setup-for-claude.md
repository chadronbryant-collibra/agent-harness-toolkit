# Guide a person's setup

Open [START-HERE.md](../../START-HERE.md) and follow only the guide for the outcome the person selects. If they already named a task or folder, start there. Browser chat can explain the choices. Local setup requires a session that can read and write the target folder.

1. **Find the target.** Distinguish the extracted download from the work folder. Confirm the actual work folder and read its existing instructions. Check Python before previewing helper setup. If a prerequisite is missing, explain what it is for and guide the person through the official installation only if they choose it. For a new folder, create it after the person chooses its location. For an existing folder, preview additions and show any conflicting paths. Keep existing instructions and settings. If the task needs a change to them, show the proposed edit and recheck the file before applying it.
2. **Use the supplied files.** For memory, use the reviewed `kit.py add memory-harness` preset and the [memory reference](memory.md). For other outcomes, use the copy map in the selected guide. Copy files as written and customize only what the person asks for. When Python is available, the optional [setup helper](../learn/advanced.md) can show the file plan and copy the preset. A ready-made script is preferable to generating another one.
3. **Check the outcome.** For skills, open a fresh Claude Code session in the target and invoke the selected skill. For memory, tell the person to start a fresh Local session in the work folder, then save one explicit practice item and test a plain-language recall question in a second session. If the skill does not run, name it as the fallback instead of treating file search as memory. For context, reopen the folder and read the named source. For a connection, verify the current account and read one item the person named. Report what actually opened or ran, and identify the remaining action if the client lacks access.

Memory writes, external connections, paid runs, and delegation follow the person's selected scope. Use a fictional note for practice. Check local file permissions and storage before saving real notes. For existing connectors, use the current client's supported account and tool discovery. Never ask the person to paste a token or copy someone else's configuration.

Leave the person with the install path, the prompt to reuse, and the result of the check. For updates, compare the existing copy against the new preset and preserve their edits. For removal, review the exact files to remove and keep any notes or work the person created.
