Add outcome-based setup, four reusable skills, context and reference starters, guided connection checks, and optional local setup and project scripts. Move the workshop to optional practice. Add a public walkthrough with three selectable examples.

Add a self-contained workshop, setup choices for new and existing folders, and a fresh-session exercise that checks the current source against saved progress. Keep the Python helper available for optional tools and settings. Metered previews check available budget, show covered tools, and report observed overruns.

Reworked the setup page, every guide, working-instruction template, agent role and starter lesson in plain language. Added copyable prompts, a guide directory, configuration explanations and a separate command reference for Claude and maintainers. The home-page download now points to the source with the refreshed guides. No runtime behavior or permissions changed.

Introduced guided setup, Windows/macOS launchers, model choices, spending records, task progress, agent roles, optional local memory, reminders and a way to package the toolkit. Included fictional examples and automated checks.

Live account use, fresh Claude loading and a colleague's walkthrough remain separate checks. See the [recorded checks](docs/validation-2026-10-30.md) and [check your setup](docs/acceptance.md).
